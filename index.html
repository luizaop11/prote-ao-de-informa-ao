Criptografia por substituição

Transforme letras e números usando regras simples, como nas primeiras atividades em Python.

Como funciona?

As letras minúsculas são substituídas por um dicionário baseado no teclado QWERTY. Letras maiúsculas seguem a mesma regra, números podem ser deslocados e símbolos são preservados.

Esta cifra é apenas didática. Não utilize para proteger senhas reais.

02

Laboratório de hash

Observe como uma entrada é transformada em um resumo numérico de tamanho fixo.

—

Entenda o algoritmo

valor = 0
for letra in senha:
    valor = valor * 31 + ord(letra)
    valor %= 2**32
resultado = f"{valor:08x}"

O cálculo acima é uma demonstração de hash simples, não uma função segura para armazenar senhas. O tamanho fixo do resultado não impede colisões.

Em sistemas reais, utilize algoritmos próprios para senhas, como Argon2id, scrypt ou bcrypt, com salt exclusivo.

O que acontece?

O cadastro calcula um hash didático. No login, o sistema calcula novamente o hash da senha digitada e compara os resultados.

Esta simulação não é um sistema de autenticação real. O hash utilizado não é seguro, os dados ficam apenas no navegador e não há servidor ou banco de dados protegido.

Por que o tamanho importa?

O número de combinações é calculado como caracteres possíveis elevados ao comprimento da senha. Dobrar o conjunto de caracteres ou aumentar o comprimento pode elevar muito o esforço necessário.

Boas práticas de segurança

Revise os conceitos aprendidos e aplique-os ao criar suas próprias senhas.

🔑

Senhas únicas

Não reutilize a mesma senha em vários serviços.

📏

Comprimento

Prefira senhas longas ou frases-senha difíceis de adivinhar.

🧂

Salt e hash

Sistemas reais usam salts únicos e algoritmos específicos para senhas.

🛡️

Autenticação extra

Ative a autenticação multifator sempre que possível.
